# ADR-004 SSH和审批执行边界

日期 2026-11-20；状态 Accepted（本轮设计决定，不代表后续实现）。

## 原设计
V1 OpenSSH优先及简化线性状态机。

## 决策与原因
部署固定Collector、strict host key，禁通用exec；32A本地有效审批先于deep；任一活动阶段可取消，attempt只追加。远端SSH命令字符串需封闭构造；审批非空ID不足；取消不丢证据。

## 影响与权衡
14/32A/36；执行前授权复核与签名计划绑定。无已发布业务代码需迁移；原V1字节保留。

## 对应验证
hostkey/auth/sudo/重放/过期/取消/资源压力；实际结果见执行报告，未来控制PLANNED。
