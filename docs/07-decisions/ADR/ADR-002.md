# ADR-002 证据与检测状态

日期 2026-11-20；状态 Accepted（本轮设计决定，不代表后续实现）。

## 原设计
V1 Schema证据字段不全，需求验收曾允许Finding或覆盖不足。

## 决策与原因
Finding必须非空真实同host-scan证据；缺证据用RuleResult UNKNOWN，完整证据版本/hash/integrity单独字段。防止无证据发现和失败假绿；hash缺失不能填假摘要。

## 影响与权衡
领域/Schema/规则/报告/AI，结果契约独立新版本。无已发布业务代码需迁移；原V1字节保留。

## 对应验证
引用篡改/跨host-scan/缺证据/Schema反例；实际结果见执行报告，未来控制PLANNED。
