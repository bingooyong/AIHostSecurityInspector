# ADR-007 维护中的YAML与版本化工具许可

日期 2026-11-20；状态 Accepted（本轮设计决定，不代表后续实现）。

## 原设计
V1未固定解析库与工具版本。

## 决策与原因
YAML组织go.yaml.in/yaml/v4 v4.0.0；YARA保留但维护模式，YARA-X后续评估；Wazuh按版本组件核许可。官方调研避免归档库与错误许可假设；新增依赖仅需求必要。

## 影响与权衡
资产解析、依赖锁定、工具评估；不嵌入GPL/AGPL工具代码。无已发布业务代码需迁移；原V1字节保留。

## 对应验证
恶意YAML/固定版本SBOM/依赖漏洞/Adapter验收；实际结果见执行报告，未来控制PLANNED。
