# 安全边界

设计契约已建立；运行防护仅以实现/测试证据计。默认READ_ONLY。

## 主机权限

仅明确authorized且Profile允许的host_id；IP不是身份。目标解析只允许登记ID/组，不接受IP段扩展、任意command/script/SQL；一组混合越权全部拒绝。plan无网络；执行重新验证资产版本、主机身份、策略、审批和窗口。开发不连生产。固定部署Collector受控版本/root-owned且普通巡检用户不可改，专用非root账号；不接受任意sudo/上传执行，禁止NOPASSWD ALL。

SSH不得关闭known_hosts/HostKeyCallback，错误指纹失败；不得降级其他地址、密码明文、忽略目标身份。审批不是非空字符串，deep/IR要求可验证审批绑定plan_hash/目标/Profile/范围/执行者/审批者/到期/nonce，操作审批分离。

## 允许与禁止副作用

允许查询本机状态、读取批准日志/元数据/hash、经审查只读工具；扫描器日志/报告和证据写入仅在批准目录；文件atime、登录审计/缓存副作用必须披露。禁止杀进程、删除/隔离、安装卸载、修改服务/配置/网络/账号、防火墙或执行任意Shell。无自动修复。未来处置另建独立模块，不能复用扫描权限。

## 输入与资源

资产/规则/工具输出/主机数据/模型输出均跨信任边界。严格字段/枚举/大小/深度/路径；规则DSL不能eval/脚本，执行工具固定二进制和argv白名单（不通过sh -c）。深度路径白名单且拒绝symlink/mount逃逸、排除DB/备份/网络挂载；最大文件数/大小/总字节/递归/IO/时间/并发、维护窗和压力终止均由执行器强制。无执行器的离线plan只能描述不能声称已强制执行。

## AI/报告

默认关闭AI；最小字段脱敏视图、禁原始日志/凭据/环境/样本；外发另需政策授权，本地模型同样做脱敏。不提供模型tool calling执行能力，主机文本只能是数据。结构化校验+引用属于本scan/host允许证据集合，不改规则severity。失败保留确定性报告。Markdown/HTML需转义不可信文本与链接，不自动跟随URL。

## 证据与来源

raw/normalized/analysis分开；hash校验/manifest不可省略，未知hash显式null/状态；引用真实且同host/scan；签名、信任根和反重放证明来源，不能把自算SHA256当真实性保证。证据/审批/审计只追加，有权限隔离与留存策略。无证据RuleResult UNKNOWN而非空引用Finding。
