# 数据治理

原始证据仅本地/授权安全域留存；标准化用于确定性规则；AI视图只包含批准字段、匿名化host/user/address/path类别、必要摘要与真实evidence_id。原始与标准化均可含敏感数据，不能因为JSON就外发。完整命令行、用户名/IP清单、原始日志、私钥/Token/密码/环境/连接串/样本禁止默认外传。
