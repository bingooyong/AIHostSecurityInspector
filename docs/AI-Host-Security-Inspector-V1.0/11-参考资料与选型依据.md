## 方法论说明
- NIST SP 800-137 可用于建立持续监控策略，关注资产可见性、威胁和控制有效性。
- NIST SP 800-61 Rev. 3（2025）将事件响应融入 CSF 2.0 风险管理。
- CIS Benchmark 必须按具体 OS / 版本选择，不能跨发行版直接套用。
- MITRE ATT&CK 可用于行为分类，应固定采用版本并核对更新。

## 许可证审查
引入工具前确认开源许可证、商业使用、二次分发、修改嵌入、病毒库 / YARA / SCAP 内容的独立许可，以及第三方情报源的使用和再分发条款。
