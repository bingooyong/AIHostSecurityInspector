# 08. 实施路线、测试策略与验收标准

## 1. 实施阶段

### WP0：现状调查
交付：主机资产、OS / 版本 / 架构、网络区域、访问路径、账号权限、堡垒机、维护窗口、数据外发审批、现有安全工具。
验收：每台试点主机明确授权人、环境等级、访问方式和允许 Profile。

### WP1：CLI 骨架
交付：Go Module、CLI、Host / ScanJob / Evidence / Finding 模型、JSON Schema、YAML 解析、dry-run、授权校验。
验收：未授权主机、非法 Profile、无审批 deep 任务均被阻断。

### WP2：Linux Collector
模块：host_identity、process_inventory、network_inventory、account_inventory、service_inventory、persistence_inventory、security_config、package_inventory。
验收：测试 VM 上采集数据与人工核对一致；权限不足明确报告。

### WP3：规则和报告
交付：YAML 规则、规则版本、正反例、Finding 证据引用、JSON / Markdown 报告、历史差异。
验收：每条 finding 可定位 evidence；缺失采集不能显示 PASS。

### WP4：专业工具集成
依次接入 osquery、Lynis、OpenSCAP、ClamAV、YARA。
验收：工具缺失、版本不兼容、超时和返回码异常均可识别；不自动删除文件。

### WP5：AI 与 Skill
交付：Provider Adapter、脱敏器、结构化输出、Prompt Injection 防护、Codex / Claude Skill。
验收：AI 只能引用真实 evidence_id；AI 不可用时规则报告仍完整。

### WP6：MCP 与托管
交付：MCP Server、扫描 API、区域 Runner、任务签名、结果回传、审批和审计。
验收：Agent 无法调用任意 Shell；越权主机请求被拒绝。

### WP7：Web 平台
资产中心、任务中心、风险中心、证据详情、规则和例外管理、RBAC、报告和趋势。

## 2. 测试策略

### 单元测试
YAML 解析、命令白名单、规则条件、Schema、脱敏器、状态机、SHA-256、AI evidence_id 校验。

### 集成测试
使用一次性 Linux VM / 容器：
- SSH 指纹错误、超时、认证失败。
- 权限不足、工具缺失。
- ClamAV / YARA 适配器。
- 离线结果包导入和完整性校验。
- 模型超时、429、无效 JSON、Provider 不可用。

### 安全测试
- Agent 请求未授权主机。
- deep 无审批。
- 进程参数中注入伪指令。
- 日志包含密码、Token、连接串。
- 结果包和规则包篡改。
- SSH host key mismatch。
- 参数注入尝试执行任意 Shell。
- 路径穿越。
- 失败状态被错误显示为 PASS。

### 检测效果测试
- 在隔离测试环境使用 EICAR 测试文件验证杀毒集成。
- 使用自建无害 YARA 样本验证规则。
- 使用模拟进程、启动项验证规则。
- 构造正常业务进程基线检查误报。
- 覆盖不同 Linux 发行版和架构。
不得在生产主机投放真实恶意样本。

## 3. 验收指标建议
| 指标 | 建议要求 |
|---|---|
| 授权控制 | 未授权主机扫描成功数 = 0 |
| 只读边界 | 扫描前后无非预期配置变更 |
| 证据关联 | finding evidence 引用有效率 100% |
| 采集完整性 | 每模块有成功 / 失败 / 跳过 / 不适用状态 |
| 规则可复现 | 正例和反例测试全部通过 |
| AI 引用 | 不存在证据 ID 的引用数 = 0 |
| AI 降级 | 模型不可用仍生成规则报告 |
| 敏感信息 | 测试密钥不出现在模型请求和报告 |
| 审计 | 每次扫描可追溯执行人、主机、Profile 和版本 |
| 性能 | 按主机类型建立 quick / standard / deep 基准 |

## 4. 试点顺序
1. 3～5 台非关键测试主机，覆盖不同发行版和架构。
2. 1～2 台 UAT 主机。
3. 生产先做 quick，观察资源和误报。
4. standard 经评审后逐台试点。
5. deep 必须维护窗口和书面审批。
不建议首批全网并发扫描。

## 5. 发布门禁
编译、单元测试、lint、依赖扫描、Collector 命令审查、规则正反例、Schema 兼容、安全边界、SBOM、构建摘要和版本追溯全部通过。
