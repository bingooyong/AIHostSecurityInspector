# 04. 巡检范围与检测规则目录

## 1. 检测能力边界
“没有检测到恶意行为”不等于“主机绝对没有木马”。报告必须说明工具、规则库、采集权限、扫描范围和覆盖限制。建议采用：主机状态 + 进程与网络 + 账号与持久化 + 文件完整性 + ClamAV / YARA + 漏洞匹配 + 基线 + 日志关联；必要时再用 Velociraptor 深入取证。

## 2. Linux 巡检矩阵

| 模块 | 采集内容 | 典型异常 | Profile |
|---|---|---|---|
| 主机身份 | OS、内核、架构、启动时间 | 未登记、身份变化 | quick |
| 进程 | PID、PPID、UID、路径、启动时间、命令行摘要、哈希 | 临时目录执行、孤儿进程、二进制已删除 | quick |
| 网络 | 监听端口、连接、进程关联、路由 | 未登记监听、异常外联 | quick |
| 账号 | 用户组、登录、sudo、SSH Key 元数据 | 新增高权账号、异常登录、公钥变化 | quick |
| 服务 | systemd、init、守护进程 | 未授权服务、异常路径 | quick |
| 持久化 | cron、timer、rc.local、profile、at | 可疑启动脚本 | quick |
| 文件权限 | SUID/SGID、world-writable、capabilities | 异常提权入口 | standard |
| 关键配置 | sshd、sudoers、PAM、hosts、ld.so.preload | 配置篡改 | standard |
| 安全控制 | 防火墙、SELinux、AppArmor、auditd | 防护关闭、审计缺失 | standard |
| 软件包 | 包名、版本、来源 | 过期或未知软件 | standard |
| 漏洞 | 软件版本与本地 CVE 情报 | 已知高危漏洞 | standard |
| 恶意文件 | ClamAV | 特征命中 | standard / deep |
| 特征扫描 | YARA | 可疑家族特征 | deep |
| 完整性 | 关键目录哈希和元数据 | 未授权变更 | deep |
| 日志 | auth、sudo、audit、系统日志摘要 | 爆破、异常提权、日志清理线索 | standard / deep |
| 容器 | 容器、镜像、特权、挂载 | 特权容器、异常挂载 | P2 |

## 3. 进程异常规则

| ID | 检测点 | 初始严重度 | 注意事项 |
|---|---|---|---|
| PROC-001 | 进程存在但可执行文件不存在 | High | 排除合法升级或短生命周期 |
| PROC-002 | 进程从 `/tmp`、`/var/tmp`、`/dev/shm` 执行 | Medium | 路径本身不是恶意结论 |
| PROC-003 | root 进程不在主机角色基线内 | Medium / High | 核实业务用途和父进程 |
| PROC-004 | 进程名称与路径不匹配 | Medium | 核对 inode、哈希、包归属 |
| PROC-005 | 未登记进程监听外部可达端口 | High | 结合防火墙和区域 |
| PROC-006 | 进程连接异常目的地址或端口 | Medium / High | 需要网络基线和情报 |
| PROC-007 | 异常父子进程链 | Medium | 结合业务上下文 |
| PROC-008 | 未知内核模块 | High | 核对模块来源和签名 |
| PROC-009 | 高权限进程启动时间异常 | Medium | 对照变更窗口 |
| PROC-010 | 命令行含疑似凭据参数 | Info / High | 先脱敏，不能暴露原文 |

## 4. 网络规则
- NET-001：未登记监听端口。
- NET-002：业务主机出现不符合角色基线的端口。
- NET-003：进程发起异常外联。
- NET-004：短时间大量连接失败。
- NET-005：监听进程路径位于临时或用户可写目录。
- NET-006：防火墙停止或关键规则缺失。
- NET-007：DNS 配置偏离区域基线。
- NET-008：发现异常代理、隧道或端口转发配置。

首期只采集本机网络状态，不对其他 IP / 网段主动探测。

## 5. 账号和持久化规则
- IAM-001：新增 UID 0 账号。
- IAM-002：新增 sudo / wheel 高权成员。
- IAM-003：SSH authorized_keys 新增或变化。
- IAM-004：长期未使用账号突然登录。
- IAM-005：异常失败登录。
- PERS-001：新增未知 systemd service / timer。
- PERS-002：新增 cron / at 任务。
- PERS-003：shell profile 出现未知启动命令。
- PERS-004：`/etc/ld.so.preload` 存在未授权内容。
- PERS-005：异常 rc.local、init 或 udev 规则。
- PERS-006：内核模块与允许列表不一致。

## 6. 文件与恶意软件规则
- MAL-001：ClamAV 命中。
- MAL-002：YARA 命中经过审查的规则。
- MAL-003：关键系统文件哈希与可信基线不一致。
- MAL-004：未知可执行文件位于高风险目录。
- MAL-005：新出现 SUID / SGID 文件。
- MAL-006：服务可执行文件所有者或权限异常。
- MAL-007：关键目录出现异常隐藏可执行文件。
- MAL-008：Rootkit 相关异常信号。

必须记录工具版本、病毒库 / YARA 规则版本和扫描范围。工具未运行不能解释为“未发现病毒”。

## 7. 安全基线
SSH 认证策略、账号锁定、审计服务、防火墙、SELinux / AppArmor、不必要服务、系统补丁、关键目录权限、时间同步、日志轮转与留存。优先使用与目标 OS / 版本匹配的 OpenSCAP / SCAP Security Guide 或经批准 CIS Benchmark，不允许模型临时生成生产基线。

## 8. Windows 后续范围
进程与父子关系、签名和路径、Services、Scheduled Tasks、Run Keys、WMI Subscription、Startup Folder、本地管理员组、RDP、登录事件、Defender 状态与排除项、PowerShell / Sysmon 日志、防火墙、共享、补丁、驱动和启动项。采用签名 PowerShell 或 Go Windows Collector。

## 9. Profile
- quick：身份、进程、网络、账号、服务、自启动、关键配置。
- standard：quick + 软件包漏洞匹配、基线、指定路径文件扫描。
- deep：standard + 扩展文件扫描、YARA、关键文件完整性和更多日志。
- incident-response：事件驱动定向采集，需审批和证据保管链。

## 10. 规则质量
每条规则必须有 ID、版本、平台、Profile、前置条件、证据字段、确定性逻辑、严重度、置信度初值、误报说明、正例和反例、来源和审查人。规则变更需测试、灰度和版本化。
