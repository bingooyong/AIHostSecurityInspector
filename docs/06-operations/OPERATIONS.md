# 运维、故障与证据治理

状态：PLANNED；本轮建立运维契约，无常驻服务、真实扫描历史或运营指标。首切片日常使用仅为离线资产与计划检查。

## 1. 执行前检查

确认真实主体、授权清单版本、目标身份、安全域与 Profile；先生成计划并审阅模块/工具/路径/限额/盲区。deep/IR 检查有效审批、维护窗口和资源压力。执行前重新授权，不能复用失效计划；未确认主机、版本、指纹或路径时停止该目标，不扩大到其他 IP/网段。

## 2. 故障处理

| 情况 | 平台应记录 | 运维动作边界 |
|---|---|---|
| SSH 认证/指纹错误 | CONNECT/AUTH/HOST_KEY 分类、失败模块 | 核对登记与凭据；不关闭 host key 校验或尝试其他地址 |
| 权限不足 | PERMISSION_INSUFFICIENT、覆盖缺口、UNKNOWN | 独立评审最小权限；不自动提权/改 sudoers |
| 工具/规则内容缺失或过期 | TOOL_NOT_INSTALLED/CONTENT_STALE | 另走软件/规则分发，不扫描时安装下载 |
| 超时/资源压力 | 总/模块 deadline、CPU/IO/RSS/文件量、PARTIAL | 停止新工作保留证据；调整后需新计划/审批 |
| 取消 | CANCELLED、已完成证据、未运行模块 | 检查子进程有界退出；重试新 attempt |
| 磁盘满/写失败 | STORAGE_ERROR、完整性 unverified/failed | 停止采集，不覆盖旧证据；按治理恢复容量 |
| 摘要/签名/引用错误 | EVIDENCE_HASH_FAILED 等、隔离对象 | 不导入正式结果或生成可信结论；调查来源 |
| AI 故障/无效引用 | ai_status=failed 与错误码 | 继续规则报告；不扩大外发数据或无限重试 |
| 疑似高危事件 | 规则证据、限制、人工复核状态 | 保存证据和调查建议，授权负责人另行处置 |

“没有命中”“模块失败”“无权限”“未覆盖”是不同结果，任何故障都不能转为 PASS 或“主机无木马”。

## 3. 指标与结构化日志

后续记录任务/模块耗时、成功/部分/失败/取消数、覆盖分母、UNKNOWN、连接/权限错误、资源压力停止、证据总量/校验失败、工具和内容版本、AI 请求/延迟/失败/成本、授权/审批拒绝与 Runner 在线状态。标签不携带原始敏感日志、用户名/IP 清单或任意路径，避免高基数泄漏。

日志至少有时间、event/error_code、request/scan/host/attempt ID（存在时）、actor、安全域、outcome 和版本。stdout 保持命令结果；stderr 结构化诊断；密钥、完整 argv/环境/原文资产文件不可记录。日志链式哈希只是篡改线索，不能当成外部不可抵赖证明。

## 4. 规则与基线维护

规则/策略/病毒库/YARA/SCAP/漏洞情报离线更新，固定来源/版本/摘要/许可、审查与正反例；灰度后批准，保留回滚包。基线由授权人员审核，不自动把首次扫描结果当可信允许表；合法变更带审批，版本差异仍保留原观察。

误报/确认/接受风险/整改/复测由人工反馈事件记录，禁止模型反馈直接成为生产规则。复测未覆盖或失败不能关闭历史 Finding；fixed 需要可比范围的有效证据。

## 5. 备份、恢复与留存

SQLite/平台数据库与文件/对象证据使用一致快照，备份 manifest、规则/策略/Schema 和签名公钥；凭据单独受控，不进普通明文备份。恢复后核对对象 hash、ID 关系、任务/attempt 与报告引用，旧 RUNNING 任务标记中断，重试重新授权。

留存周期、加密要求、法律保全和原始日志访问审批由企业数据治理确定，当前未提供数值。无策略不自动删除调查证据。原始对象导出比普通报告权限更严格，导出应审计对象集合与用途；不将原始敏感资料上传外部模型。

## 6. 事件与升级边界

HostSec 不自动杀进程、删文件、隔离主机、停服务、封 IP 或改账号。高危信号只保存证据、停止未经授权的范围扩展、生成需人工复核报告；是否定向 IR、隔离或修复由企业授权人员在独立流程决定。本轮不会发送通知或联系其他人员。

升级/回滚、证书/密钥轮换、数据库迁移和 Collector 安装均有独立操作授权与验证，不混入只读巡检。运维手册条目只有在对应功能及恢复演练完成后才能从 PLANNED 更新为 IMPLEMENTED。
